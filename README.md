## 🚀 Getting Started

Follow these steps to run the practical programs on your computer.

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Open the project folder**

```bash
cd JAVA-PRACTICALS
```

**3. Compile a Java program**

```bash
javac Main.java
```

**4. Execute the program**

```bash
java Main
```

Make sure Java JDK is installed and configured on your system.
